Welcome to the raw code aesthetic. This style prioritizes information density and readability for technical users. No distractions, just the data you need.

Quick Start

Initialize the landing page generator with the following command:

# Install via NPM
npm install @cuonghoa/landing-page-cli

# Initialize project
const app = require('cuonghoa');
app.generate({
    style: 'monospaced',
    theme: 'solarized'
});

This will create a structured directory perfect for documentation, technical specs, or developer portfolios.
