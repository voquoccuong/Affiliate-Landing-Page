# WeSuccess Style Guide

## I. Color Palette
### Backgrounds
- **Primary BG:** `#111111` (Deep Black) representing premium/tech.
- **Secondary BG:** `#1A1A1A` (Dark Gray) for cards/sections.
- **Tertiary BG:** `#0A0A0A` (Darker Black) for contrast sections.

### Typography Colors
- **Primary Text:** `#FFFFFF` (White)
- **Secondary Text:** `#A0A0A0` (Muted Gray)
- **Accent/Highlight:** `#C9A962` (Champagne Gold) - Used for emphasis and key value props.

### Interface Colors
- **Primary Button (CTA):** `#22C55E` (Vibrant Green)
  - **Gradient/Glow:** Often used with `box-shadow: 0 0 30px rgba(34, 197, 94, 0.35)`
- **Borders/Dividers:** `rgba(255, 255, 255, 0.1)`

## II. Typography
**Font Family:** `Be Vietnam Pro`, sans-serif.

### Heading Styles
- **H1 (Hero):** 
  - Size: `60px` - `72px` 
  - Weight: `800` (ExtraBold)
  - Line-height: `1.1`
  - Letter-spacing: `-1.5px`
- **H2 (Section Titles):**
  - Size: `40px` - `48px`
  - Weight: `700` (Bold)
  - Margin-bottom: `20px`
- **H3 (Card Titles):**
  - Size: `24px` - `30px`
  - Weight: `600` (SemiBold)

### Body Text
- **P (Standard):**
  - Size: `16px` - `18px`
  - Line-height: `1.6`
  - Color: `#A0A0A0`

## III. Layout & Spacing
- **Container Max-width:** `1200px` (or `1280px` for wide screens).
- **Section Padding:** `80px 0` for standard sections. `120px 0` for Hero.
- **Grid Gap:** `24px` to `32px`.
- **Border Radius:**
  - Standard Cards: `24px`
  - Buttons: `12px` or `50px` (Pill shape)
  - Images: `16px`

## IV. Visual Effects
- **Glassmorphism:** Used for badges and floating elements.
  - `background: rgba(255, 255, 255, 0.05)`
  - `backdrop-filter: blur(10px)`
  - `border: 1px solid rgba(255, 255, 255, 0.1)`
- **Gradients:**
  - Background glows: Radial gradients of Cyan (`#06b6d4`) or Purple (`#8b5cf6`) often placed behind product images.
- **Shadows:**
  - Strong drop shadows on floating product mockups to create depth.

## V. Components
### Buttons
**Hero CTA:**
- Bg: `#22C55E`
- Text: White, Bold, Uppercase
- Padding: `20px 48px`
- Hover: Scale 1.05 + Brighten

**Secondary Button:**
- Bg: Transparent
- Border: `1px solid rgba(255,255,255,0.2)`
- Text: White
