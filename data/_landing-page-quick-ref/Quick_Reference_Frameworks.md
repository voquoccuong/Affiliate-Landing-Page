# 🎯 QUICK REFERENCE - FRAMEWORKS & FORMULAS

## 1. THE VALUE EQUATION (Hormozi)

```
VALUE = (Dream Outcome × Perceived Likelihood) / (Time Delay × Effort & Sacrifice)

⬆️ INCREASE:                    ⬇️ DECREASE:
- Dream Outcome                 - Time Delay
- Perceived Likelihood          - Effort & Sacrifice
  (via proof + guarantee)        (via simplification)

IMPACT RANKING:
1. Effort & Sacrifice (easiest to decrease)
2. Time Delay (medium effort)
3. Perceived Likelihood (harder, needs proof)
4. Dream Outcome (hardest, needs research)

⚡ QUICK WIN: Focus on #1 (Effort), then #2 (Time)
```

## 5. HEADLINE FORMULAS

```
FORMAT 1: LOSS AVERSION (Most effective)
"You're Losing $[X] By NOT [Outcome]"
Example: "You're losing $120k/year by not having a $10k/month offer"

FORMAT 2: ASPIRATION
"Go From [Current] to [Desired] in [Timeframe]"
Example: "Go from $0 to $50k/month in 90 days"

FORMAT 3: POSITIONING
"[Problem] Without [Old Way Friction]"
Example: "Premium consulting clients without being a celebrity"

FORMAT 4: CURIOSITY
"What If [Outcome] Was [Adjective]?"
Example: "What if closing deals was actually easy?"

FORMAT 5: COMMAND
"[Verb] Your [Result] in [Timeframe] Using [Method]"
Example: "Build your $10k offer in 30 days using this framework"

FORMAT 6: CONTRAST
"The [Old] Way vs The [New] Way to [Outcome]"
Example: "The outdated vs modern way to build consulting practices"

🏆 RULE: FORMAT 1 converts 2-3x better than others
```

## 6. CTA BUTTON FORMULA

```
[ACTION VERB] + [BENEFIT/REASON] + [URGENCY]

✅ GOOD:
"Reserve Your Spot - Ends Friday"
"Claim Your Access - Only 3 Left"
"Start Your Free Trial - No Credit Card"

❌ WEAK:
"Submit" | "Next" | "Click Here" | "Sign Up"

ACTION VERBS THAT CONVERT:
Claim, Reserve, Secure, Start, Book, Get, Access, Apply

URGENCY ADDS 50-100% LIFT:
"...Now" = +20%
"...Before Friday" = +50%
"...Only 3 Left" = +100%
```

## 9. GUARANTEE STRUCTURE

```
LEVEL 1 - WEAK:
"30-day money back guarantee"
Impact: +30-50% conversion lift

LEVEL 2 - MEDIUM:
"30-day money back OR free bonus training"
Impact: +80-120% conversion lift

LEVEL 3 - STRONG (Hormozi favorite):
"Get [result] in [time] or we work for free until you do"
Impact: +150-250% conversion lift

LEVEL 4 - ULTRA-STRONG:
"Triple your money back if you don't [outcome]"
OR "Jump in shark-infested water to get it back or full refund"
Impact: +200-300% conversion lift

🏆 RECOMMENDATION:
Start Level 2 → Graduate to Level 3 → Test Level 4
```

## 10. PRICING PSYCHOLOGY

```
ANCHORING EFFECT:
❌ "Price is $299"
✅ "Price is usually $499. Today: $299"
   Impact: +40-60% lift

VALUE STACKING:
❌ "Package: $200"
✅ "Training ($150) + Templates ($75) + Scripts ($50)
   Total: $275 → Today: $199"

PAYMENT PLAN:
"$99/mo × 3 months" feels like $99
"$297 total" feels like $297
Same price, different psychology

PRICING TIERS:
✅ 2-3 tiers (recommend 1 as "Most Popular")
❌ 4+ tiers (choice paralysis)
```

## 11. MOBILE OPTIMIZATION

```
60-80% of traffic is MOBILE

CRITICAL:
1. Single column layout
2. Sticky CTA (+30-50% mobile conversions)
3. Button size: 48x48px minimum
4. Form: 3 fields max (45% completion vs 25% for 5+)
5. Text: 16px+ body, line height 1.5+
6. Load speed: <2 seconds (compress images <200kb)
7. No auto-play video, no pop-ups on load
```

## 14. QUICK DIAGNOSTIC

```
WHY ISN'T IT CONVERTING?

STEP 1: Check TRAFFIC QUALITY
- High bounce (>70%)? = Wrong audience
- Low scroll (<30%)? = Messaging doesn't resonate
→ Fix traffic source first

STEP 2: Check HEADLINE
- Does it clearly state benefit?
- Would YOU click on it?
→ A/B test 2 headlines first

STEP 3: Check FORM FRICTION
- How many fields? (Should be 3-5 max)
- Completion rate <60%? = Too many fields
→ Reduce fields

STEP 4: Check CREDIBILITY
- Do you have testimonials?
- Specific metrics/results?
- Clear guarantee?
→ Add specific social proof

STEP 5: Check OFFER
- Is it compelling enough?
- Solving real problem?
- Guarantee addresses risk?
→ Strengthen positioning

TYPICAL ISSUE DISTRIBUTION:
40% = Wrong traffic source
30% = Weak messaging
20% = High friction
10% = Weak offer
```

## 20. COMMON MISTAKES TO AVOID

```
❌ Too many CTAs (use 1 primary)
❌ Too many form fields (max 3-5)
❌ Generic testimonials ("Great!")
❌ No guarantee (lose 30-50% conversions)
❌ No urgency/scarcity (lose 200-300%)
❌ Weak headline (loses 80% of readers)
❌ No mobile optimization (lose 60-80%)
❌ Slow page load (>2 sec = 50% bounce)
❌ Testing multiple elements at once
❌ Not enough traffic to test (need 50+ conversions)

✅ DO INSTEAD:
✅ 1 primary CTA, repeated
✅ 3 fields: Name, Email, Phone
✅ Specific testimonials with results
✅ Creative guarantee (Level 3-4)
✅ Clear deadline + scarcity
✅ Loss aversion headline
✅ Mobile-first design
✅ <2 sec page load
✅ Test 1 element per week
✅ Wait for statistical significance
```
