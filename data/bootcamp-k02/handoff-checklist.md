# Handoff Checklist - Landing Page Bootcamp K02

Use this checklist khi bàn giao cho AI/dev để không sót hạng mục. Đánh dấu `[x]` khi đã xong.

## 1) Outputs & Files
- [ ] `01-research.md` (context, avatar, USP, pricing) ✅ mã hóa UTF-8
- [ ] `02-content.md` (bố cục + nội dung chi tiết)
- [ ] `03-assets.md` (đủ 9 ảnh testimonial + alt text, logo, favicon, OG image)
- [ ] `04-style-guide.md` (bản hợp nhất, prompt-ready)
- [ ] `05-implementation-plan.md`
- [ ] `index.html` (hoặc phiên bản mới nhất của landing)
- [ ] Các file phụ: `style-guide-02.md` (tham khảo), `index-2.html`, `index-3.html` (nếu cần so sánh)

## 2) Nội dung & Flow
- [ ] Hero: headline/subhead/CTA chính/phụ đã final (copy + link đích)
- [ ] Offer/Pricing: tên gói, giá, bullet lợi ích, highlight gói Cam Kết
- [ ] FAQ: ít nhất 5-7 objections chính, copy final
- [ ] Social proof: caption/người nói/ảnh rõ nguồn
- [ ] Legal: Điều khoản/Chính sách bảo mật/Hoàn tiền link thật
- [ ] CTA flow rõ: form đăng ký hay chuyển checkout? (link đích có UTM)

## 3) Assets
- [ ] Logo + favicon đủ kích thước (32/64), định dạng PNG/ICO
- [ ] 9 ảnh testimonial (LadiCDN) + alt text + thứ tự hiển thị
- [ ] Video: Youtube ID/URL embed, đã kiểm play
- [ ] OG image: đã chụp/gán vào meta `og:image`

## 4) Style Guide Ready
- [ ] Palette, typography, spacing scale, radius, shadow, icon style
- [ ] States: hover/active/focus cho button/link
- [ ] Motion: mức độ (fade-up nhẹ, pulse badge)
- [ ] Accessibility: contrast AA, font-size tối thiểu, focus ring
- [ ] Prompt cho `@mcp:ui-ux-pro-max` đã kèm tham chiếu (3-5 site thích/ghét)

## 5) Implementation & Tracking
- [ ] Tailwind CDN + Alpine.js đã khai báo
- [ ] Aspect-ratio video chuẩn 16:9
- [ ] Lazyload ảnh testimonial
- [ ] GA4/Pixel đã gắn đúng ID (nếu có)
- [ ] Schema/SEO cơ bản: title/description/canonical/og/twitter

## 6) QA & Launch
- [ ] DevTools device mode: 360px → 1440px không vỡ layout
- [ ] Cross-browser: Chrome/Edge desktop, Chrome/Safari/Firefox mobile (hoặc tương đương)
- [ ] Links không 404, tel/mailto hoạt động
- [ ] Lighthouse (perf/accessibility/SEO/best-practice) > 85
- [ ] Kiểm tra contrast, focus, keyboard tab qua CTA chính

## 7) Outstanding TODOs
- [ ] Liệt kê các mục chưa đủ (ví dụ thiếu 3 ảnh testimonial còn lại, policy link thật, OG image)
