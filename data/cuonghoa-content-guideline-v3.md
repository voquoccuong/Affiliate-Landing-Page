## 🎯 TỔNG QUAN WEBSITE

### Định vị
**"Nền tảng học tập AI Automation toàn diện từ các dự án và công việc thực tế."**

### Đối tượng mục tiêu
| Priority | Đối tượng | Pain point |
|----------|-----------|------------|
| **Primary** | SME Owners, Managers | Muốn tối ưu vận hành bằng AI nhưng không biết bắt đầu từ đâu |
| **Secondary** | Freelancers, Specialists | Muốn nâng cao kỹ năng để tăng giá trị bản thân |
| **Tertiary** | Nhân viên văn phòng | Muốn làm việc hiệu quả hơn, tiết kiệm thời gian |

### Thông điệp chính
> **"Học = Làm luôn"**  
> Không lý thuyết suông, mỗi buổi học ra được sản phẩm thực tế

### Load More Logic (Section 4, 5, 6)
```javascript
// Configuration
const CONFIG = {
  INITIAL_ITEMS: 8,      // Hiển thị ban đầu
  LOAD_MORE_COUNT: 4     // Mỗi lần click load thêm
};

// Implementation
function loadMore(sectionId) {
  const section = document.getElementById(sectionId);
  const currentCount = section.querySelectorAll('.item:not(.hidden)').length;
  const hiddenItems = section.querySelectorAll('.item.hidden');
  
  // Show next 4 items
  for (let i = 0; i < CONFIG.LOAD_MORE_COUNT && i < hiddenItems.length; i++) {
    hiddenItems[i].classList.remove('hidden');
    hiddenItems[i].classList.add('fade-in');
  }
  
  // Hide button if no more items
  if (hiddenItems.length <= CONFIG.LOAD_MORE_COUNT) {
    section.querySelector('.load-more-btn').style.display = 'none';
  }
}
```

### Filter Tabs
```javascript
function filterByCategory(category, sectionId) {
  const section = document.getElementById(sectionId);
  const items = section.querySelectorAll('.item');
  
  items.forEach(item => {
    if (category === 'all' || item.dataset.category === category) {
      item.style.display = 'block';
    } else {
      item.style.display = 'none';
    }
  });
}
```
